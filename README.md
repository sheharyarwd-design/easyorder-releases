# EasyOrder POS — Updates

This repository contains **installer releases only** (the same Setup file customers receive).

The application source code lives in a PRIVATE repository and is not published here.

## Install / Update

1. Download the newest `EasyOrder-Setup_vX.Y.Z.exe` from [Releases](../../releases/latest)
2. Run it — installing over an old version keeps all data.

Inside the app: **Settings > Check for Updates**.
